## 2026-05-20 - Roving Tabindex for Workout Tabs
**Learning:** Implementing the WAI-ARIA Tabs pattern with roving tabindex and keyboard navigation (arrows, Home, End) significantly improves the UX for power users and screen reader accessibility. Synchronizing `aria-selected`, `tabindex`, and the `hidden` attribute ensures the interface is both visually and semantically correct.
**Action:** Use the roving tabindex pattern for all collection-based interactive elements (tabs, menus, carousels) to provide a standard-compliant, efficient keyboard experience.

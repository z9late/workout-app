## 2025-05-14 - WAI-ARIA Tab Pattern for Workout Modules
**Learning:** Standardizing tabbed interfaces with WAI-ARIA roles and roving tabindex significantly improves accessibility for keyboard and screen reader users in this dark-themed UI.
**Action:** Use `role="tablist"`, `role="tab"`, and `role="tabpanel"` with `focus-visible:ring-red-500` for all future collection-based navigation components in this repository.
